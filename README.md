# RTL-to-GDSII ASIC Design using OpenLANE and SKY130

## Overview

This repository contains my implementation of the VSD OpenLANE Workshop, demonstrating the complete open-source RTL-to-GDSII ASIC design flow using the SKY130 Process Design Kit (PDK).

The project covers synthesis, floorplanning, placement, clock tree synthesis (CTS), routing, timing analysis, physical verification, and custom standard cell integration using OpenLANE, OpenROAD, Magic, and ngspice.

## Tools Used
- OpenLANE
- OpenROAD
- Magic VLSI
- ngspice
- SKY130A PDK
- Tcl
- Docker

## Workflow
1. RTL Synthesis
2. Floorplanning
3. Placement
4. Custom Inverter Layout Design
5. SPICE Extraction and Characterization
6. LEF Generation
7. Custom Cell Integration
8. Clock Tree Synthesis (CTS)
9. Static Timing Analysis (STA)
10. Power Distribution Network (PDN)
11. Routing
12. SPEF Extraction
13. Post-Route Timing Analysis


## Key Learning Outcomes
- Open-source ASIC design flow
- Custom standard cell design using Magic
- SPICE extraction and post-layout simulation
- LEF generation and integration into OpenLANE
- Static Timing Analysis using OpenSTA
- Clock Tree Synthesis
- Routing using TritonRoute
- Physical verification using Magic
